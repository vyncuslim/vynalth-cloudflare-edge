# VWAF v2.0 RC3 — evidence and trust boundaries

This candidate adds a bounded signed intelligence refresh library, a portable runtime smoke-test matrix, and an evidence summarizer. Production policy, routes, telemetry, honeypot, notifications and existing fixture denominators are unchanged.

## Qualification status

- The original 162 attack scenarios remain unchanged. The ten generic URL scenarios remain misses until reviewed application destination contracts exist. Do not manufacture a 99% score.
- The intelligence refresh function requires a privileged, explicitly approved HTTPS feed URL and Ed25519 public key. A durable adapter must initialize an explicit zero sequence and atomically compare-and-swap the verified manifest and high-water mark. No feed, trust anchor, durable adapter, scheduler or runtime consumer is provisioned by this PR. Indicators remain advisory only. Network addresses are not identities.
- Runtime matrix uses local Fetch requests on Node, Deno and Bun. CI must pass before claiming tested compatibility. This is not cross-cloud production deployment or shared distributed-state qualification.
- The evidence summarizer requires independently exported per-check observations over an explicit window. Missing slots remain missing, and duplicate retries cannot conceal failed samples. 30 days of continuous monitoring and independent provenance/scope review are still required. A point-sample SLI does not certify an SLA.
- Full OWASP Top 10 depends on application controls beyond the WAF. Route schema enforcement must match versioned backend contracts; free text must not be rejected simply for containing code examples.
- Independent human review, production load and availability evidence, complete route inventory, distributed rate limit/state recovery, and verified origin protection remain open. No live attack or production load traffic is generated by these tests.

Run locally: node --test src/vwaf-intel-refresh.test.js test/vwaf-availability-evidence.test.js ; node scripts/vwaf-portable-smoke.mjs ; npm run vwaf:acceptance. The formal GA gate remains blocked until qualified evidence is available.
